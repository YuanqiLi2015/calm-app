# 本地治愈音乐文件夹 (Local Healing Music)

你可以通过以下 **两种方式** 使用你本地保存的治愈音乐（App 默认开启自动播放，右上角可随时一键静音）：

1. **方式一（最方便，支持手机与电脑）：直接在 App 内导入**
   - 点击 App 顶部导航栏的 **「🎵 音乐」** 按钮
   - 点击 **「📂 导入我本地保存的音乐 (.mp3 / .m4a / .wav)」**
   - 选中的音乐文件会直接永久保存在你 iPhone 浏览器的本地数据库（`IndexedDB`）中，下次打开 App 会自动播放你导入的音乐，无需重复选择！

2. **方式二：直接放入此 `music/` 文件夹**
   - 你也可以把本地音乐文件重命名为 `my-calm.mp3`（或放入此文件夹并在 `playlist.json` 中登记），App 启动时会自动加载。
   - 目前文件夹内已预置一首无缝循环的 432Hz + 528Hz 深海冥想疗愈音 `default-calm.wav` 作为初始音乐。
